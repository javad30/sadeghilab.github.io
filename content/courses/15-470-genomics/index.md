## Course Overview

**Course Code:** BIOL 15.470  
**Institution:** Department of Biology, Brandon University  
**Instructor:** Dr. Javad Sadeghi  

### Description
An advanced course focusing on high-throughput sequencing technologies, genome annotation, comparative genomics, and bioinformatics pipelines. Students gain hands-on experience handling real omics data using computational tools (e.g., Python/R, command-line genomics tools).

### Key Topics
- Next-generation sequencing (NGS) platforms and library prep
- Genome assembly, annotation, and variant calling
- Microbial community profiling (16S rRNA / metagenomics)
- Multi-omics integration and evolutionary genomics
